# InfiniteScript — Phase 1–8

InfiniteScript is designed around one principle:

POWERFUL BY DEFAULT.
SIMPLE BY DEFAULT.

A beginner should be able to write:

Say "Hello"

while advanced developers can build:

- Applications
- Games
- Servers
- APIs
- Desktop software
- Native Windows software
- UI
- 2D graphics
- 3D graphics
- Automation
- Developer tools
- Libraries
- Packages
- Services

## Phase 1
Core language.

## Phase 2
Objects and custom types.

## Phase 3
Advanced runtime.

## Phase 4
Files, data and networking.

## Phase 5
Infinite UI.

## Phase 6
Animation.

## Phase 7
Graphics and 3D.

## Phase 8
CLI and developer tooling.

The language should favour simple words while keeping advanced
capabilities available.

InfiniteScript should not artificially restrict developers.
