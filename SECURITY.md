# Security Policy

The InfiniteScript project takes security issues seriously.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Report suspected security vulnerabilities privately through the contact method
provided by the official project repository.

Include:
- a description of the vulnerability
- affected version
- steps to reproduce
- potential impact
- any relevant proof-of-concept information

## Do not include

Never send:
- passwords
- API keys
- private user information
- authentication tokens
- unrelated personal information

## Responsible disclosure

Please allow maintainers reasonable time to investigate and fix a reported
security issue before publicly disclosing technical details.

## Supported versions

Security support depends on the project's current development and release
status.
