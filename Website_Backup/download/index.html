Get InfiniteScript

Set up InfiniteScript on Windows and write your first .infs program.

Development build

InfiniteScript is currently under active development. Releases and installers will be added as the runtime matures.

Windows

InfiniteScript currently runs from its command-line executable. Download the latest release from the project's GitHub Releases page when an official release is available.

Open GitHub ?

Install

1. Download InfiniteScript
2. Extract the release
3. Open PowerShell
4. Navigate to the InfiniteScript folder
5. Run:

Inf help

Check your installation

Run: 

Inf version

You should see the installed InfiniteScript version.

Run your first program

Say "Hello World"

Save the file as Hello.infs, then run: 

Inf run Hello.infs
