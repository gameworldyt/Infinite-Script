Learn InfiniteScript

Start from zero and work your way toward building real programs.

Beginner path

01 Your First Program Write and run your first InfiniteScript program. 02 Variables Store numbers, text and boolean values. 03 Functions Turn repeated behaviour into reusable code. 04 Control Flow Make your programs make decisions and repeat work.

Learn by building

Once you understand the basics, try building a calculator, text adventure, simple game system, inventory system, or UI application.
