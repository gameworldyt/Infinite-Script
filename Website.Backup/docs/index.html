InfiniteScript Documentation

Welcome to InfiniteScript — a programming language designed to be simple to learn while remaining powerful underneath.

Current version: v0.2

InfiniteScript is actively being developed. Some features documented here may change as the language evolves.

What is InfiniteScript?

InfiniteScript is a readable programming language built around clear commands, simple syntax, and a growing runtime.

Instead of requiring complicated syntax for basic operations, InfiniteScript lets you express what you want your program to do directly.

Your first program

Create a file ending in .infs and write: 

Say "Hello, World!"

Run the program using the InfiniteScript CLI: 

Inf run Hello.infs

Variables

Variables can store numbers, text, and boolean values. 

Local Storage Money = 100
Local Storage PlayerName = "Adan"
Local Storage IsAdmin = true

Changing values

Change Money by 50

Set Money = 500

Conditions

Use If, Else If, Else, and End to control program flow. 

If Money >= 100
    Say "You have enough money."
Else
    Say "Not enough money."
End

Functions

Functions let you package reusable behaviour. 

Function GiveMoney Amount
    Change Money by Amount
    Return Money
End

GiveMoney 50
