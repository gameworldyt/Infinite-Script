InfiniteScript Engine

Animation Engine

InfiniteScript includes a dedicated animation system designed for smooth transitions, reusable tracks, easing, sequences, groups, repetition and physics-based motion.

Browser demonstration
The demonstrations below run in your browser so you can explore the concepts interactively. The production InfiniteScript animation engine is implemented in C++.

Interactive playground

AnimationTrack • interpolation • easing

Animation capabilities

?? Interpolation Animate numeric values and structured properties.
?? Easing Linear, cubic, quartic, quintic, exponential, circular, back, elastic and bounce easing.
??? Keyframes Create tracks containing multiple animation points.
?? Sequences Run animations one after another.
?? Groups Run multiple animations together.
?? Repetition Support one-shot and repeating animation modes.
?? Control Pause, resume, cancel, reset and reverse animations.
?? Springs Physics-style spring motion is available in the engine.
