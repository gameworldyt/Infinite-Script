Why InfiniteScript

Designed to stay simple.

InfiniteScript focuses on readable commands and a unified runtime, allowing the language to grow from simple scripts into complete applications.

⌘

Readable Syntax

Write code that looks close to the way you describe what your program should do.

∞

One Ecosystem

Language, runtime, UI, packages, storage and future systems are designed to work together.

⚡

Built for Speed

A native runtime gives InfiniteScript a foundation for responsive applications and interfaces.

🎨

Infinite UI

Build native interfaces directly from InfiniteScript without needing HTML, CSS or JavaScript.

◈

Animation

Timelines, easing, interpolation and animation systems are part of the engine architecture.

🔧

Extensible

Packages, events and engine modules allow the platform to expand without changing the language's core philosophy.

Quick Start

Code that reads naturally.
