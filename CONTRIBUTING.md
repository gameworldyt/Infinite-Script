# Contributing to InfiniteScript

Thank you for your interest in contributing!

## Before contributing

Please make sure your contribution is your own work or that you have permission
to submit it.

Do not submit:
- stolen code
- copyrighted material without permission
- malicious code
- credentials, API keys, passwords, or private information

## Pull Requests

Contributors should clearly describe:
- what they changed
- why they changed it
- how they tested it

A maintainer may accept, modify, or reject any contribution.

## Ownership

Submitting a contribution does not give you ownership of the entire
InfiniteScript project.

You retain rights to code you independently own, while granting the project
the permissions necessary to use your contribution according to the project's
license and contribution terms.

## Naming

Do not use "InfiniteScript" or "Infinite UI" in a way that suggests your fork
is an official project unless you have permission.

## Security

Do not publicly disclose an unpatched security vulnerability in an issue.
Follow SECURITY.md instead.
